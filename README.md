# Product Catalog (Nice Gadgets) 📱💻

## 🔗 Live Demo
[View the Project Live](https://igols.github.io/react_phone-catalog/)

A modern, full-featured e-commerce application for gadgets, including smartphones, tablets, and accessories. This project is built with a focus on performance, scalability, and a seamless user experience.

## ✨ Key Features
- **Dynamic Catalog:** Browse through different categories (Phones, Tablets, Accessories) with data fetched from a JSON API.
- **Advanced Search & Filtering:** Find products easily using search queries and sort them by price, age, or title.
- **Shopping Cart:** Full cart functionality, including adding/removing items and updating quantities.
- **Favorites System:** Users can save their favorite gadgets to a dedicated list.
- **Product Details:** Comprehensive pages for each item with technical specifications, high-quality image galleries, and descriptions.
- **Pagination:** Efficient handling of large product lists for better performance and UX.
- **Dark & Light Mode:** Fully implemented theme switching to suit user preferences.
- **Responsive Layout:** Optimized for all screen sizes, from mobile devices to large desktops.

## 🛠 Tech Stack
- **React** (Hooks, Context API)
- **TypeScript** (Strong typing for reliable code)
- **Vite** (Next-generation frontend tooling)
- **SCSS / BEM** (Modular and maintainable styling)
- **React Router** (Client-side routing)
- **Lucide React** (Clean and modern icon set)

## 📦 Installation and Setup
1. Clone the repository:
   git clone https://github.com/igols/react_phone-catalog.git
2. Navigate to the project directory:
   cd react_phone-catalog
3. Install dependencies:
   npm install
4. Launch the development server:
   npm start

## 📂 Project Structure
- src/api — Data fetching logic and JSON interaction.
- src/component — Reusable UI components (Buttons, Cards, Sliders).
- src/context — State management for Cart, Favorites, and Theme.
- src/layout — Global layouts including Header, Footer, and Navigation.
- src/styles — Global SCSS variables, mixins, and theme definitions.
- public/img — Static assets and product images.

## 📜 Development Scripts
- npm start — Runs the app in development mode.
- npm run build — Builds the app for production.
- npm run lint — Runs ESLint and Stylelint to check code quality.
- npm run format — Automatically formats code using Prettier.
